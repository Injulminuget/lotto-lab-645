# LOTTO LAB — 로또 6/45 기록 연구소

휴대폰 사용을 우선한 **설치형 웹앱(PWA)**입니다. 결제, 로또 판매, 로그인, 서버 또는 광고가 없습니다.

## 핵심 기능

- 최근 30/100/300/전체 회차 범위 선택
- 번호 1~45 출현 횟수·출현 비율·최근 출현 간격
- 홀짝, 저/고, 합계, 연속번호, 직전 회차 반복, 구간별 분포, 동반 출현 번호 쌍
- 회차/번호 검색, 당첨번호 및 보너스 번호 조회
- 인터넷 갱신, CSV/JSON 파일 불러오기, CSV 저장
- 기기에 데이터를 저장하여 오프라인에서 통계 열람
- PWA 홈 화면 설치, 화면 크기·안전 영역 고려한 갤럭시 모바일 UI

**주의:** 과거 기록은 미래 추첨을 예측하지 않습니다. 어떤 번호 조합이든 1등 확률은 1/8,145,060으로 같습니다.

## 실행

### 간단한 로컬 테스트 (PC)

1. ZIP 압축을 해제합니다.
2. 폴더에서 다음 명령을 실행합니다.

   ```bash
   python -m http.server 8000
   ```

3. PC 브라우저에서 `http://localhost:8000`에 접속합니다.

로컬 PC의 `localhost`에서는 PWA 기능을 테스트할 수 있습니다. **갤럭시에서 실제 홈 화면에 설치하려면 HTTPS로 정적 웹 호스팅**해야 합니다. 예: GitHub Pages, Netlify, Cloudflare Pages. 다른 기기에서 PC의 HTTP 로컬 주소로 접속한 경우에는 보안 컨텍스트가 아니어서 서비스 워커 설치가 안 될 수 있습니다.

### 갤럭시에서 설치

1. 압축을 푼 내용 전체를 HTTPS 정적 호스팅에 업로드합니다. 최상위 경로에 `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, `icons/`가 같이 있어야 합니다.
2. Chrome 또는 삼성 인터넷으로 그 주소를 엽니다.
3. 브라우저 메뉴 > **홈 화면에 추가** 또는 **앱 설치**를 누릅니다(브라우저 버전별로 표현이 다릅니다).
4. 데이터 > 인터넷에서 전체 기록 갱신을 눌러 저장합니다.

### 데이터 갱신 및 출처

- 기본 포함 데이터: 1242~1246회 **5건** (2026-10-18 현재 확인됨). 이 데이터는 *전체 이력이 아닌 시작용 데이터*이며 앱 화면에 명시됩니다.
- 앱은 첫 온라인 실행 시 공개 미러 `https://smok95.github.io/lotto/results/all.json` 를 우선 다운로드합니다. 실패하면 `https://cashlogy.kr/lotto/excel.csv` 를 시도합니다.
- **중요:** 제3자 제공처의 서비스 상태나 CORS 설정에 따라 자동 갱신이 실패할 수 있습니다. 앱에 있는 **파일 불러오기**를 통해 CSV를 직접 넣을 수 있도록 했습니다. 앱에서 온라인 전체 이력의 실제 다운로드·CORS 성공 여부는 배포 위치에서 확인해야 합니다.
- 데이터 로딩 시 번호 유효성, 중복 회차, 누락 회차, 최신 회차를 검사합니다. 온라인 전체 데이터는 1회부터 이어지는 연속 기록이어야 하며, 현재 데이터보다 오래되면 교체하지 않습니다.
- 보너스 번호는 일반번호 빈도 분석에 합산하지 않습니다.
- 로컬 저장소(localStorage)에 데이터가 저장됩니다. 브라우저 데이터를 삭제하거나 앱 도메인이 달라지면 데이터가 사라집니다. 필요한 경우 CSV로 백업하세요.

## 파일 구성

- `index.html` — 화면 구조
- `styles.css` — 반응형 디자인
- `app.js` — 데이터 검증, 통계, UI, 로컬 저장
- `manifest.webmanifest` — PWA 메타데이터
- `sw.js` — 앱 셸 오프라인 캐시
- `icons/` — 아이콘 이미지

## 검증

- PWA 셸, 모바일 화면, 통계 계산, CSV 가져오기 및 내보내기 등을 로컬 테스트할 수 있습니다.
- 동행복권과 무관한 개인용 비공식 학습·분석 앱입니다. 당첨 및 지급 정보는 반드시 공식 발표로 최종 확인해야 합니다.
